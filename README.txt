AJNESHWAR ENTERPRISES — BACKEND ORDER SYSTEM

Run:
1. Install Node.js LTS.
2. Open this folder in Terminal/Command Prompt.
3. Run: npm install
4. Run: npm start
5. Website: http://localhost:3000
6. Admin orders: http://localhost:3000/admin

Orders are saved in orders.json.
Delivery: below ₹500 = ₹80; ₹500+ = FREE.
WhatsApp is optional confirmation; automatic WhatsApp business notifications require WhatsApp Business Platform/API.
Do not put API secrets in index.html.
